🔍 Filter Students

📊 Student Search: Use the filters below to find students based on their skills, department, and semester. You can use any combination of filters or leave them empty to see all students.
Examples: Java, Python, React, Machine Learning

💡 Search Tips

  • Skill Search: Enter any part of a skill name. For example, "Java" will find students with "Java", "JavaScript", etc.
  • Multiple Filters: Combine filters to narrow down results. For example, search for "Python" skills in "Computer Science" department.
  • Case Insensitive: Search is not case-sensitive, so "java" and "Java" will give the same results.
  • Partial Matches: Skill and department searches support partial matching for more flexible results.
